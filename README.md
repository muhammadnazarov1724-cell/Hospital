## Как получить лечение?
1. Узнайте, входит ли интересующее вас лечение в программу для вашего региона
2. Подготовьте необходимые документы и отправьте заявку на лечение
3. В течение 3-х рабочих дней специалист отдела ОМС свяжется с вами по указанному вами номеру телефона
